# DocuMind — Multi-Document Agentic RAG System

DocuMind is an intelligent document analysis system that helps users understand complex PDFs and legal documents using hybrid retrieval, multimodal processing, and agentic AI workflows.

## Features

- Multi-document PDF processing
- Text, table, and image extraction
- Hybrid retrieval (semantic + keyword)
- Intelligent query routing
- Source-based answers with citations
- Legal document simplification

## Tech Stack

- Python
- PyMuPDF
- pdfplumber
- LangChain
- LangGraph
- ChromaDB
- BM25
- Gemini 1.5 Flash
- Streamlit
